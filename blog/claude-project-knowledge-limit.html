What Happens When Claude Project Knowledge Approaches the Context Limit?

Projects on claude.ai keep files that Claude reads in every chat of the project. Here is what happens as those files grow past what fits in one context window, and what to do when Claude asks you to remove files.

November 17, 2026 6 min read Guide
Quick answer

When a project's knowledge approaches the context window, Claude switches the project to RAG mode on paid plans (Pro, Max, Ultra, Team and Enterprise). Instead of loading every file into each chat, Claude uses a project knowledge search tool to pull the passages that matter, which the Help Center says expands capacity by up to 10x. On the Free plan this retrieval mode is not available, so all project files have to fit in the context window. If you see a message like "project knowledge exceeds maximum. remove files to continue", remove or shorten files until the project fits, or move to a paid plan where RAG takes over.

How does project knowledge normally work?

A project on claude.ai is a workspace with its own chats, instructions and a knowledge base. You upload documents, text, code or other files once, and Claude uses them as background in every chat inside that project. Projects are available on every plan, including Free, where you can create up to five projects.

While the knowledge base is small, Claude loads it into the context window of each chat. That works well: Claude sees every file in full, so it can quote from any of them and compare them directly. The catch is that the context window is finite, and every file you add uses part of it in every message.

What changes when the knowledge base gets close to the limit?

The Help Center article on RAG for projects describes the switch:

  • It is automatic. When project knowledge approaches or exceeds the context window, Claude enables RAG mode on its own. You cannot pick the mode by hand.
  • Claude searches instead of reading everything. A project knowledge search tool retrieves the relevant passages for each question. You can see Claude using that tool when it looks something up.
  • Capacity goes up. The article says projects can store up to 10x more content this way.
  • It can switch back. If you remove files and the knowledge drops below the threshold, Claude can return to loading everything in context.
  • There is an indicator. A visual marker shows when a project is RAG-enabled.
  • Paid plans only. Enhanced project knowledge with RAG is available on Pro, Max, Ultra, Team and Enterprise.

What does that mean for the quality of answers?

Retrieval changes what Claude sees. In context mode, Claude has every file in front of it. In RAG mode it sees the passages the search returns for the current question. For most lookups ("what does the contract say about termination?") that is all it needs. For questions that require the whole set at once, such as "compare all twelve reports and rank them", the answer depends on whether the search surfaces every relevant part.

Practical ways to get better results once a project is in RAG mode:

  • Name the document. "In the Q3 board memo, what..." gives the search a clear target.
  • Use the words the files use. If the files say "termination for convenience", ask with those words, not a paraphrase.
  • Split big comparisons. Ask about each document in turn, then ask for the comparison from those answers.
  • Ask for quotes. Asking Claude to quote the passages it relied on makes it easy to check that the right parts were found.

Why do I see "project knowledge exceeds maximum. remove files to continue"?

The Help Center does not document that exact wording, so treat this as the most likely reading rather than an official definition. The message means the project holds more than Claude can use as it stands. The two common cases:

  1. Free plan. RAG for projects is a paid feature, and the upload article says project files must fit in the context window. Once they do not, you need to remove files.
  2. A single upload is too large. Project uploads are capped at 30MB per file, a lower limit than the 500MB for files attached to a chat.

To clear it:

  1. Remove files the project no longer needs, such as old drafts and duplicates.
  2. Convert long PDFs to plain text or Markdown. Text carries the same words in less space than scanned pages.
  3. Cut boilerplate: appendices, repeated headers, legal footers and tables of contents.
  4. Split one large project into several focused ones, for example one per client or per subject.
  5. On the Free plan, upgrading to a paid plan lets RAG handle larger knowledge bases.

Is this the same as Claude Code running out of context?

No. Projects on claude.ai and Claude Code sessions manage context differently. Claude Code summarizes older conversation history automatically when a session approaches its limit, and you can run /compact or /clear yourself. See what happens when the Claude Code context window fills up for that side.

FAQ

Can I turn RAG mode on or off for a project?

No. Claude decides based on how much knowledge the project holds. It switches to RAG near the context limit and can switch back if the knowledge shrinks.

Does RAG mode cost more usage?

The Help Center does not list a separate charge. Retrieval usually means less text per message than loading every file, but usage on paid plans is still governed by your plan's limits.

Why did Claude miss something that is in my project files?

In RAG mode Claude only sees what the search returns. Name the file, use the document's own wording, or ask Claude to search the project knowledge for a specific term.

Do projects on the Free plan get RAG?

No. Enhanced project knowledge with RAG is only available on paid plans, so on Free the files must fit in the context window.
