The 10 Fastest-Growing Claude Skills of 2026

Ten skill repos picked up more than 230,000 GitHub stars between them in October 2026. Here is what each one does, who should install it, and where to get it.

November 22, 2026 9 min read Rankings
Quick answer

The fastest-growing Claude skills of October 2026 were Matt Pocock Skills (+35.3K stars), Ponytail (+32.6K) and Cloudflare's Security Audit (+31.4K), followed by Impeccable, Anatomy, Diagram Design, Graphify, Superpowers, Taste Skill and Hallmark. Three trends stand out: engineering discipline (planning, TDD, smaller diffs), security review, and design skills that fight generic "AI-made" interfaces.

1. Matt Pocock Skills: an engineering process in a folder

Repo: github.com/mattpocock/skills · October: +35.3K stars

Matt Pocock, known for his TypeScript teaching, published the skills he uses every day as "Skills for Real Engineers". It is a set rather than a single skill: tdd for red-green-refactor with tests worth keeping, grilling that interviews you about a plan until every decision is settled, to-spec and to-tickets to turn a conversation into a spec and issues, triage, diagnosing-bugs, and modelling skills such as domain-modeling and codebase-design. A one-time setup-matt-pocock-skills run configures your issue tracker and docs layout.

Install it if you want Claude to work like a careful senior engineer: question first, write the spec, then build test-first.

claude plugin install mattpocock-skills@claude-plugins-official

2. Ponytail: the laziest senior dev in the room

Repo: github.com/DietrichGebert/ponytail · October: +32.6K stars

Ponytail tackles the most common complaint about coding agents: they write too much. It switches Claude into "lazy senior dev" mode, where the goal is the smallest change that fully solves the task and a reply a busy person can read once. It has three levels (lite, full, ultra) and companion skills for reviews, audits and tracking technical debt. Saying "be lazy", "simplest solution" or "yagni" triggers it.

Install it if your pull requests come back with extra abstractions, unasked-for refactors or new dependencies.

/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail

3. Security Audit: Cloudflare's verified review workflow

Repo: github.com/cloudflare/security-audit-skill · October: +31.4K stars

Cloudflare's skill runs multi-phase security audits of codebases, APIs, services, CLI tools and libraries. Its rule is strict: a finding counts only if it crosses a real trust boundary, with a concrete affected principal, resource or outcome. Each finding is independently verified and comes with source evidence, a safe reproduction, a priority and the smallest effective fix. That cuts the long lists of speculative warnings that make AI security reviews hard to act on.

Install it if you ship code that handles user data, auth or payments and want a defensive review before release.

npx skills add https://github.com/cloudflare/security-audit-skill

4. Impeccable: a design vocabulary for your agent

Repo: github.com/pbakaus/impeccable · October: +24.9K stars

Paul Bakaus's skill gives Claude a set of design commands you can steer with: critique and audit to review, bolder, quieter, colorize, typeset and layout to change direction, polish and harden to finish. It covers websites, dashboards, app UI, native mobile screens and design systems. A companion CLI, npx impeccable detect, scans a folder or a live URL for design problems.

Install it if you already have an interface and want to improve it step by step rather than regenerate it.

npx impeccable install

5. Anatomy: explain a system as a physical machine

Repo: github.com/wheresryan22/anatomy · October: +23.1K stars

Anatomy draws detailed, interactive isometric SVG figures that show a technical idea as a real object: a test rig, a dial gauge, a cabinet of drawers, a lock. Figures have many small shaded parts, a title card with a live readout and calm motion, and can include WebGL effects such as fire, water or lamp light in the same perspective. It works in plain TypeScript or React and can print a figure as an A4 PDF. It had the highest growth relative to its size in the top 10: it gained most of its stars in a single month.

Install it if you write docs, blog posts or landing pages and want a hero illustration that explains how something works.

npx skills add wheresryan22/anatomy -g

6. Diagram Design: editorial diagrams from a prompt

Repo: github.com/cathrynlavery/diagram-design · October: +20.5K stars

Cathryn Lavery's skill produces branded diagrams as HTML, SVG or PNG: architecture and data-flow diagrams, sequence and state machines, ER models, swimlanes, Gantt charts, Sankey, Wardley maps, user journeys and dozens more. It imports existing .drawio, Mermaid, Excalidraw and PlantUML files, so you can restyle what you already have.

Install it if you need architecture or process diagrams for design docs and presentations that look consistent.

npx skills add cathrynlavery/diagram-design

7. Graphify: a queryable map of your codebase

Repo: github.com/Graphify-Labs/graphify · October: +17.1K stars

Graphify turns a folder of code, docs, SQL schemas, configs and PDFs into a persistent knowledge graph with community detection. You get an interactive HTML view, GraphRAG-ready JSON and a plain-language GRAPH_REPORT.md. Claude can then answer "what depends on this?" with graph queries instead of reading dozens of files, which saves context on large repositories.

Install it if you work in a large or unfamiliar codebase. See also our guide to working with large codebases in Claude Code.

uv tool install graphifyy

8. Superpowers: brainstorm, plan, then build

Repo: github.com/obra/superpowers · October: +16.5K stars

Jesse Vincent's Superpowers is an agentic skills framework and a development method. Before writing code Claude brainstorms the design with you, writes a plan, then carries it out with test-driven development, systematic debugging, subagent-driven execution and a verification step before it calls anything done. It is one of the two largest skill repos on GitHub; it ranks lower here only because its growth is now steady rather than new.

Install it if you want one complete workflow rather than picking individual skills.

/plugin install superpowers@claude-plugins-official

9. Taste Skill: art direction for landing pages

Repo: github.com/Leonxlnx/taste-skill · October: +15.2K stars

Taste Skill is aimed at public web pages: landing pages, portfolios, product pages. Its main skill, design-taste-frontend, draws on a study of curated gallery sites and deals a full direction (concept, composition, type, palette, imagery, section blueprints), then checks the result in a real browser and fixes what looks off. It works across HTML, React, Next.js, Vue, Svelte and Astro. It is not meant for dashboards or app screens.

Install it if your marketing pages look templated and you want them to read as designed.

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

10. Hallmark: an anti-slop floor for new pages

Repo: github.com/Nutlope/hallmark · October: +14.1K stars

Hallmark, from Hassan El Mghari (Nutlope), sets a hard floor against the visual defaults every model was trained into, and deals a different direction each time so two builds in a row do not converge on the same look. It has three modes: build from a prompt, redesign <path> and audit <path>. It only touches an existing design when you name it, which keeps it from rewriting pages you are happy with.

Install it if you build new sites or pages often and want each one to look distinct.

npx skills add nutlope/hallmark -g

What the 2026 skill ranking tells us

  • Process beats prompts. The top two spots and Superpowers are about how the agent works (question, plan, test, keep it small), not about a single task.
  • Design is the biggest category. Four of the ten (Impeccable, Taste Skill, Hallmark, Anatomy), plus Diagram Design, exist to make output look less generic.
  • Big companies now ship skills. Cloudflare's Security Audit, released in June 2026, gained more stars in October than almost any community repo.
  • Skills are portable. Almost every repo here installs into Cursor, Codex and OpenCode as well as Claude Code through the shared SKILL.md format.

Tip: don't install all four design skills at once. Their descriptions overlap, so Claude has to guess which one you meant. Pick one for new pages (Hallmark or Taste Skill) and Impeccable for improving existing ones. Run /skills to see what is loaded and how many tokens each description costs.

How to install a Claude skill

There are three common routes, and each repo above lists the one it supports:

  1. Plugin marketplace inside Claude Code: /plugin marketplace add owner/repo, then /plugin install name@marketplace.
  2. The skills CLI from your terminal: npx skills add owner/repo. Add -g to install for every project.
  3. Manually: copy the skill folder into ~/.claude/skills/ (all projects) or .claude/skills/ (this project only).

To write your own, read How to Create a Claude Code Skill With SKILL.md.

FAQ

What is the most popular Claude skill in 2026?

By October 2026 growth, Matt Pocock Skills led with about 35,300 new GitHub stars. By total stars, Matt Pocock Skills and Superpowers are the two largest, each above 320,000 as of November 22, 2026.

Do these skills work outside Claude Code?

Most of them do. They follow the open SKILL.md format, so the skills CLI can install them for Cursor, Codex, OpenCode and other agents as well as Claude Code.

Will installing many skills slow Claude down?

Only a little. At startup Claude sees each skill's description, not its body. The full SKILL.md loads when the skill is used. Overlapping skills, such as three design skills, can compete for the same requests, so keep the ones you actually use.

Which skills should a beginner install first?

Superpowers or Matt Pocock Skills for an engineering process, Ponytail to keep changes small, and one design skill (Impeccable, Taste Skill or Hallmark) if you build interfaces.
